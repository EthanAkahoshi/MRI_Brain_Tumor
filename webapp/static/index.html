      Reading the heatmap

      Grad-CAM marks the regions that pushed the model toward its answer. Red mattered most, blue least.

      A strong highlight doesn't mean the answer is right. If the heat sits on the skull, the background or the image edges, the model may be using the wrong cues.

      The map is coarse, built from a 16×16 grid and scaled up, so it doesn't outline the tumour.

      Limitations

      • Trained on a few thousand public MRI slices, without patient information or clinical validation.
      • It does worse on scans from sources it wasn't trained on, and it misses some tumours. A "No tumour" result never rules one out.
      • Scores are not calibrated probabilities. A 99% score does not mean a 99% chance.
      • It gives an answer for any image, even ones that aren't brain MRIs.
      • Each scan is shrunk to the model's input size, so small details can be lost.
